# 기술 문서

## 디스크 구조
- 게임 데이터는 거의 전부 `PSP_GAME/USRDIR/assets00.naz` 한 파일(약 730MB)에 들어 있습니다.
- 디렉터리는 파일 끝(0x2bec91f1)에 있고, 파일 이름은 바이트마다 오른쪽 2비트 회전(ror2)으로 가려져 있습니다(`tools/naz.py`).
- 게임은 블록 단위로 읽기 때문에 파일의 물리 순서를 유지한 채 통째로 다시 씁니다. 크기가 바뀐 파일 뒤의 오프셋은 모두 밀어서 디렉터리를 갱신합니다(`tools/isonaz.py`).

## 텍스트
- `/data/Localize/*.txt` 에 해당하는 텍스트 블록이 `.main`/`.map` 파일 안에 들어 있습니다(`tools/loctext.py`).
- 블록 = 16바이트 디스크립터 4개: D0 보조(타임코드 f32), D1 u16 슬롯 오프셋, D2 허프만 비트열, D3 트리 루트.
- 허프만 비트열은 LSB 우선, 내부 노드 값 0x0A74. 객체는 64바이트 정렬이며, 섹션 헤더(매직+0x14)에 객체 영역 크기가 있습니다.
- 줄바꿈은 문자 그대로의 `\n` 두 글자입니다.

## 한글 코드
- 엔진은 글리프 맵을 부호 있는 16비트로 이진 탐색하고, 자동 줄바꿈 때 하위 바이트가 0인 문자를 문자열 끝으로 취급합니다.
- 그래서 실제 사용하는 한글을 U+04A1부터(하위 바이트 A1~FE만 사용) 차례로 다시 배정했습니다.

## 글꼴
- `ODMidText_24`(본문, CLUT8)과 `ODMidText_24_Stroke3`(외곽선, CLUT4) 두 객체를 다시 만듭니다(`tools/font.py`).
- 텍스처를 256×512에서 512×512로 키우고, 기존 글리프와 한글을 모두 0.63배로 줄여 재배치합니다. 화면 표시 크기는 원래와 같습니다.
- 한글은 나눔스퀘어네오 Bold에 기울임 0.08을 줘서 4배로 그린 뒤 축소합니다. 쌍자음이 들어간 글자는 Regular 굵기를 가로 1.2배로 그려 작은 크기에서도 두 획이 구분되게 했습니다.
- 외곽선 글꼴은 본문 글자를 12픽셀(4배 기준) 팽창해 만듭니다.

## 그림 글자 (`tools/imgpatch.py`)
- 부팅 화면·콘셉트 아트는 `data_psp/textures/.../*.texture_psp` 독립 텍스처입니다. 512×272 RGBA8888, 스위즐, 픽셀 데이터는 파일 끝에 있습니다.
- 메뉴·HUD·레벨 텍스처는 `.main`/`.map` 객체 안에 GE 명령 목록(TBP·TBW·TSIZE·TPSM)과 함께 들어 있고, 픽셀 주소는 로드할 때 정해집니다. 그래서 PPSSPP 디버거로 RAM·VRAM을 덤프해 GE 명령 목록을 찾아 텍스처를 디코딩했습니다(CLUT4/8, 16/32비트, DXT1/3/5). 영어 글자는 게임 로고뿐이었습니다.
- 부팅 화면: 원본 노란 글자의 행(117–126, 134–143, 150–160, 167–176, 184–193, 201–210)과 줄 너비(411·417·451·421·357·125px, x=240 가운데 정렬)를 측정했습니다. 원본 글자와 외곽선을 inpaint로 지우고, 한글을 같은 높이로 그린 뒤 가로 배율 1.25배와 자간 1px 이내로 원본 너비에 맞춥니다(넘지 않음). 외곽선 1.6px와 (1,2) 그림자도 원본과 같습니다.
- 콘셉트 아트: 라벨은 원본 글자 상자를 측정해 지운 뒤 같은 중심에 갈무리9로 씁니다. 스토리보드는 대사 칸 안쪽을 칸 테두리만 남기고 지운 뒤 원본 첫 줄 위치(위·왼쪽)에서 갈무리7로 씁니다. 원본 글자 높이는 5~6px로 한글을 읽을 수 없는 크기라 높이만 7px로 키웠습니다.
