# 번역 지침

- 기계 번역을 쓰지 않고 직접 번역했습니다.
- 멕시코 서부극 풍의 B급 액션 분위기를 살려, 대사는 거칠고 짧은 구어체로 옮겼습니다.
- 주인공 Ramiro는 「라미로」, 스토리 이름 El Gringo Loco는 「엘 그링고 로코」처럼 고유명사는 소리대로 적었습니다.
- 메뉴·HUD는 원본 칸 너비를 넘지 않도록 짧게 줄였습니다. 작은 글씨 화면은 실제 게임에서 잘림 여부를 확인했습니다.
- 원문의 줄바꿈 `\n` 은 원문 위치를 기준으로 한국어 길이에 맞게 다시 넣었습니다.
- 게임 버튼 기호(✕ □ △ ○) 등 제어 문자는 원문 그대로 둡니다.
